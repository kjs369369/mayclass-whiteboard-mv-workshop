# 시연 대본 — 1막 35초, 25~30분 라이브

곡 하나를 화이트보드 뮤직비디오로 만드는 전 과정을 **끊지 않고** 보여주는 대본입니다.
수강생이 "이게 끝까지 돌아가는구나"를 한 호흡에 보는 게 목적이라, 3막이 아니라
**1막 35초**로 갑니다.

본문은 결국 이 한 줄입니다. 나머지는 그 한 줄이 매끄럽게 돌게 하는 준비입니다.

```
이 노래로 화이트보드 뮤직비디오 만들어줘
```

---

## 1. 곡 사양 — 이렇게 만들어 오세요

| 항목 | 값 | 이유 |
| --- | --- | --- |
| 길이 | **30~40초** | 렌더가 초당 약 6초 걸립니다. 35초면 렌더 3분 30초 |
| 구성 | 후크 하나 또는 1절 하나 | 1막 = 하나의 핵심 의미. 전개가 여러 개면 그림에 안 담깁니다 |
| 인트로 | 짧게 (3초 이내) | 긴 인트로는 그림 없는 시간이 됩니다 |
| 가사 | 4~6줄 | 그리는 요소가 5~8개 나옵니다 |
| 형식 | mp3 | wav도 되지만 파일이 큽니다 |

Suno가 보통 2~4분짜리를 주므로 **잘라서 씁니다.** 끝 3초 페이드까지 한 줄입니다.

```bash
ffmpeg -y -i suno-원본.mp3 -t 35 -af "afade=t=out:st=32:d=3" \
       -c:a libmp3lame -q:a 2 demo-cut.mp3
```

`-t 35`가 35초까지 자르고, `afade`가 32초부터 3초간 페이드아웃합니다.
레포의 `shine-cut.mp3`도 이렇게 만들어진 파일입니다.

## 2. 시연 전날 — 여기서 다 끝내둡니다

### 2-1. 환경 점검

```bash
git clone https://github.com/kjs369369/mayclass-whiteboard-mv-workshop.git
cd mayclass-whiteboard-mv-workshop
PYTHONUTF8=1 python scripts/prepare_env.py
PYTHONUTF8=1 python scripts/preflight.py
```

`preflight.py`가 **전부 `[OK]`** 여야 합니다. `[NG]`가 하나라도 있으면 그 줄의
조치를 하고 다시 돌립니다. 당일 아침에 이걸 발견하면 늦습니다.

`prepare_env.py`는 pip 설치라 2~3분 걸립니다. **당일에 라이브로 돌리지 마세요.**
시연에서는 이미 준비된 상태를 보여주고 `preflight.py` 결과만 스칩니다.

### 2-2. 이미지 생성 커넥터 확인

선화 3장을 Claude가 직접 그릴지, 프롬프트만 받아 외부에서 만들지가 여기서 갈립니다.
현재 계정에 붙어 있는 것은 셋입니다.

| 커넥터 | 도구 | 비고 |
| --- | --- | --- |
| Higgsfield | `generate_image` · `generate_image_batch` | 여러 장이면 batch가 빠릅니다 |
| Abocado | `abocado_generate_image` | 크레딧 차감 전 확인 관문이 한 번 더 있습니다 |
| Gamma | `generate_image` | |

**전날 리허설에서 셋 다 한 장씩 뽑아보고 제일 잘 나오는 걸로 정하세요.**
1막이면 필요한 건 한 장뿐이라 batch는 안 써도 됩니다.

커넥터를 안 쓰고 ChatGPT·나노바나나에 붙여넣는 것도 방법입니다. **수강생 대다수의
환경과 같아서 따라하기는 오히려 쉽습니다.** 어느 쪽이든 대본은 같고,
5번 구간에서 갈립니다.

### 2-3. 리허설 — 실제로 한 번 돌려봅니다

## 5. 구간별 대본

### ① 도입 (3분)

**먼저 결과물을 봅니다.** 설명보다 이게 빠릅니다.

```bash
start assets/whiteboard/aiclab-shine/aiclab-shine-final.mp4
```

말할 것:

> "이걸 사람이 그린 게 아닙니다. 그림은 AI가 한 장 그렸고, 그걸 **순서대로
> 드러낸** 겁니다. 펜이 지나가는 궤적은 프로그램이 계산합니다."

원리는 이 한 문장이면 됩니다.

> "노래를 재서 막을 나누고, 막마다 그림 한 장을 그린 다음, 그 그림을 **가사에서
> 사건이 일어나는 순서**대로 조각조각 드러냅니다."

화면 좌표 순서가 아니라 **가사 순서**라는 게 핵심입니다. 여기만 강조합니다.

### ② 준비 확인 (1분)

```bash
PYTHONUTF8=1 python scripts/preflight.py
```

전부 `[OK]`가 뜨는 걸 보여줍니다.

> "이게 다 초록이면 시작할 수 있습니다. 여러분도 클론하고 이거부터 돌리시면 됩니다."

`PYTHONUTF8=1`을 왜 붙이는지 한 줄만:

> "이 도구가 안내문을 중국어로 뱉는데, 한글 윈도우에서 그냥 돌리면 인코딩 때문에
> 죽습니다. 이 한 마디가 그걸 막아줍니다."

### ③ 스킬 호출 (2분)

Claude Code 창에서:

```
assets/whiteboard/demo/demo-cut.mp3 로 화이트보드 뮤직비디오 만들어줘.
1막짜리 35초야.
```

**"1막짜리"를 꼭 말합니다.** 안 그러면 스킬이 25~35초 기준으로 막을 나누려다
헷갈립니다.

말할 것:

> "지금 스킬 문서가 자동으로 읽혔습니다. 클론한 폴더 안에 `.claude/skills/`가
> 들어 있어서, 이 폴더에서 Claude Code를 열면 알아서 인식합니다.
> 따로 설치할 게 없습니다."

### ④ 곡 구조 측정 (3분)

스킬이 RMS 에너지를 재고 터미널에 막대를 그립니다. **이 화면이 시연에서 제일
설득력 있습니다.**

```
  0s  0.051  ######
  1s  0.089  ##########
  2s  0.142  #################
```

말할 것:

> "곡이 실제로 어디서 커지고 작아지는지를 잰 겁니다. 3막짜리라면 이 막대가
> 꺾이는 지점을 막 경계로 씁니다. 도구에 자막 길이로 나눠주는 기능이 있는데
> **안 씁니다** — 그건 음악을 모릅니다. 실제로 인트로 6초를 통째로 날린 적이
> 있습니다."

이어서 SRT가 만들어지는 걸 보여줍니다.

> "가사를 자막 파일로 넣지만 **화면에는 안 띄웁니다.** 그리는 순서를 정하는
> 용도로만 씁니다. 완성본에 글자가 하나도 없는 이유입니다."

### ⑤ 선화 (5분) — **확인 관문 1**

**커넥터를 쓰는 경우**: 스킬이 프롬프트를 짜고 바로 생성합니다.

**커넥터가 없는 경우**: 스킬이 프롬프트를 주고 멈춥니다. 그걸 복사해
ChatGPT·나노바나나에 붙여넣고, 나온 PNG를 `assets/whiteboard/demo/`에 넣습니다.

어느 쪽이든 프롬프트를 화면에 띄우고 두 줄만 짚습니다.

> "여기 `no stains, no paper grain` 이게 왜 있냐면 — 종이에 얼룩이 있으면
> 그림이 완성되는 **마지막 순간에 화면 전체 색이 확 바뀝니다.** 어느 영역에도
> 속하지 않은 픽셀이 한꺼번에 나타나거든요. 이 한 줄로 막습니다."

> "그리고 `NO text anywhere`. 브랜드 이름조차 글자로 안 씁니다. 기호로만
> 표현합니다."

선화가 나오면 **스킬이 멈춥니다.** 이걸 짚어줍니다.

> "여기서 물어보고 멈춥니다. 렌더가 3분 걸리기 때문에, 그림이 잘못됐는데
> 그냥 진행하면 3분을 버립니다."

### ⑥ annotation·영역 검사도 (4분) — **확인 관문 2**

스킬이 `annotation.json`을 씁니다. 파일을 열어 보여줍니다.

> "그림을 사각형으로 쪼개고, 각 조각에 **몇 번째로, 몇 초에** 그릴지를 적은
> 겁니다. `sequence`가 순서, `startMs`가 시작 시각입니다."

> "펜은 하나입니다. 그래서 시간이 겹치면 안 됩니다. 하나 끝나고 0.2초 쉬고
> 다음이 시작합니다."

이어서 영역 검사도가 나옵니다.

> "번호가 가사 순서와 맞는지 여기서 봅니다. 왼쪽부터 그리는 게 아니라
> **이야기 순서**로 그립니다."

여기서 또 멈춥니다. 이게 마지막 관문입니다.

### ⑦ 렌더 (4분) — 3분 30초 대기

```
输出尺寸: 2560x1420, 帧率: 30
```

**이 줄을 반드시 짚습니다.**

> "여기 2560이 떠야 합니다. 기본값이 1080인데, 1080으로 나오면 손 그림이
> 화면 높이의 **82%를 덮어서** 뭘 그리는지 안 보입니다. 손 크기가 픽셀로
> 박혀 있거든요."

대기 3분 30초 동안 할 이야기 — **`docs/함정노트.md`를 띄워놓고 넘깁니다.**

1. **fps 60 함정 (L절)** — "기본이 60인데 뒷단 스크립트는 30 기준이라, 그냥 두면
   카메라 무빙이 영상 절반에서 멈춥니다."
2. **펜에 남의 이름 (E절)** — "기본 펜 그림에 원작자 채널명이 인쇄돼 있습니다.
   유튜브에 올릴 거면 지운 버전을 써야 합니다. 레포에 넣어놨습니다."
3. **팬 계수 (J절)** — "카메라를 끝까지 밀면 인물이 66픽셀 잘렸습니다. 계수를
   50%로 줄여서 80픽셀 여유를 남겼습니다. 눈대중이 아니라 계산했습니다."
4. **한글 폰트 (M절)** — "영역 검사도의 글자가 □□□로 나왔습니다. 폰트가 중국어로
   박혀 있어서요. 이건 제가 고쳐서 올렸습니다."

> "이 13개가 이 레포의 진짜 값어치입니다. 코드는 원작자 것이고, 저는 **한국에서
> 이걸 돌리면 어디서 걸리는지**를 적었습니다."

## 6. 시연 중에 말하지 말 것

- **"원래는 3막인데요"** — 1막으로 줄인 걸 변명처럼 말하면 축소판으로 보입니다.
  1막도 완결된 작품입니다.
- **렌더 대기 중 침묵** — 3분 30초는 생각보다 깁니다. 함정노트를 반드시 준비합니다.
- **중국어 출력 사과** — 상류 도구가 중국어를 뱉는 건 사실이고 출처도 밝혀뒀습니다.
  "원작자가 중국 개발자입니다"로 한 문장 넘어갑니다.

## 7. 예상 질문과 답

**"내 노래가 3분인데요?"**
5~6막이 됩니다. 렌더만 18분입니다. 처음에는 40초로 연습하고, 익숙해지면 늘리세요.

**"그림을 내가 그려도 되나요?"**
됩니다. 규격만 맞으면 됩니다 — 긴 변 2560px 이상, 미색 종이, 글자 없음,
주체 사이에 여백. 손그림을 스캔해서 써도 돌아갑니다.

**"맥에서도 되나요?"**
됩니다. `.venv/Scripts/python`을 `.venv/bin/python`으로 바꾸는 것만 다릅니다.
`PYTHONUTF8=1`은 맥에서는 없어도 되지만 붙여도 무해합니다.

**"돈이 드나요?"**
Claude 구독료와, 이미지 생성 커넥터를 쓰면 그 크레딧이 듭니다. 렌더는 내 컴퓨터에서
돌아가니 공짜입니다.

**"세로 영상(쇼츠)도 되나요?"**
지금 스크립트는 16:9 고정입니다. 선화를 9:16으로 만들고 크롭·출력 크기를 바꾸면
되지만, 검증하지 않았습니다.

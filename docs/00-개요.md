# 00 · 개요 — 무엇을 만들고, 어떻게 진행하는가

## 만드는 것

노래 한 곡을 **미색 종이 위에 손이 그려나가는 16:9 화이트보드 애니메이션**으로
만듭니다. 완성 사례를 먼저 보세요.

- [케이팝 메이클래스 스케치영상](https://youtu.be/C_g08YIftkc) — 87.76초
- 레포 안의 파일: `assets/whiteboard/mayclass-dreamers/mayclass-dreamers-final.mp4`

가사는 **화면에 띄우지 않습니다.** 자막(SRT)은 그리는 순서와 시점을 정하는
용도로만 씁니다. 화면에는 글자가 하나도 없습니다.

## 원리 — 3분이면 이해할 수 있습니다

```
[음원]  ──측정──▶  막 경계 (곡 에너지가 꺾이는 지점)
                        │
[가사]  ──▶  SRT  ──▶  막마다 어떤 사건이 일어나는지
                        │
                        ▼
         막마다 선화 PNG 1장 (긴 변 2560px 이상)
                        │
                        ▼
       annotation.json — 선화를 영역으로 쪼개고
                         "몇 번째로, 몇 초에" 그릴지 지정
                        │
                        ▼
       렌더러: 영역을 순서대로 하나씩 낙묵
               (ink 선 → color 색, 2:1 비율)
               나머지 영역은 마스크로 완전히 가려둔다
                        │
                        ▼
              막별 무음 MP4 (2560x1420)
                        │
                        ▼
       ffmpeg: 16:9 크롭 → 켄번즈 카메라 무빙
                        │
                        ▼
              이어붙이기 → 음원 먹싱 → 완성
```

핵심은 두 가지입니다.

**1. 그림은 새로 그리지 않습니다.** 이미 완성된 선화 한 장을 영역별로 "가려뒀다가
순서대로 드러내는" 것입니다. 펜이 지나가는 필적은 렌더러가 자동 생성합니다.

**2. 순서는 가사가 정합니다.** 화면의 좌표 순서(왼쪽→오른쪽)가 아니라
**가사에서 사건이 일어나는 순서**대로 그립니다. 이게 이 파이프라인의 전부이고,
`annotation.json`의 `sequence`가 그걸 담습니다.

## 필요한 것

| 항목 | 버전·비고 |
| --- | --- |
| Python | 3.10 이상 |
| ffmpeg / ffprobe | PATH에 있어야 함 |
| Chrome 또는 Edge | 예뷰대의 파일 저장이 File System Access API를 씀 |
| 이미지 생성 수단 | 선화 3장 생성용. **둘 중 하나** — Claude 계정에 붙인 이미지 생성 커넥터(자동), 또는 외부 도구(ChatGPT·Nano Banana 등, 수동). [STEP 04](STEP-04-선화생성.md) 참조 |
| 음원 | 자기 곡. 없으면 레포의 `shine-cut.mp3`로 실습 |
| 디스크 | 렌더 중간 파일 포함 약 500MB 여유 |

**첫 실습은 자기 노래가 없어도 됩니다.** 레포에 메이클래스 두 편의 선화·annotation·
SRT·음원이 다 들어 있어, STEP 07(렌더)부터 그대로 재현할 수 있습니다.

## 진행 방식 — 두 갈래

### 손으로 따라하기

STEP 01부터 순서대로 명령어를 직접 칩니다. 원리를 몸으로 익히려면 이쪽입니다.
막히면 `assets/whiteboard/mayclass-dreamers/`의 실제 파일을 열어 비교하세요.

### Claude Code에게 맡기기

레포 폴더에서 Claude Code를 열고 이렇게 말합니다.

```
이 노래로 화이트보드 뮤직비디오 만들어줘
```

`.claude/skills/whiteboard-mv/SKILL.md`가 자동으로 인식돼 STEP 01~09를 대신
진행합니다. **선화 확인**과 **영역 검사도 확인** 두 관문에서 멈춰 물어봅니다.

**이미지 생성 커넥터를 붙여 뒀다면 곡만 주면 끝까지 갑니다.** 스킬이 선화까지
직접 생성합니다. 커넥터가 없으면 선화 단계에서 프롬프트를 주고 멈추므로,
그것만 외부 도구로 만들어 넣어주면 됩니다. 커넥터는 계정에 붙는 것이라
클론에 따라오지 않습니다.

두 갈래는 같은 파이프라인을 가리킵니다. 스킬 문서와 STEP 문서의 파라미터가
다르면 스킬 문서가 기준입니다.
